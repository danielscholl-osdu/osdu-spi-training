# Fieldnote S207 · Changes that come to you

**Status: published.** Level 200, the seventh and last episode of the service path. Its companion page is `chapters['changes-to-you']`, and its cut-from record is in `src/content/videos.js`; the curriculum entry is `S207` in `src/content/curriculum.js` (teaches `port-label`, `sync-cascade-labels` and `template-sync-proposes`, uses `fork-owns-few-paths` and `six-stations`, home of the myth `template-sync-overwrites`).

**Who is watching:** an engineer on the service path who has proved a change from their desk (S205) and taken it through a pull request to main (S206). **What they should believe after it:** upstream's changes reach their fork as pull requests the line opens itself, and the labels say when it is their move: sync opens a pull request into `fork_upstream` and a tracking issue labeled `human-required`; once a person merges it, the cascade starts within seconds, moves the issue to `cascade-active` and then `validated`, and opens a second pull request to main that gets the full lane and that a person merges; when the cascade cannot finish, `cascade-blocked` and a new `human-required` issue say so. Their own pull request to main that changes an upstream-owned file fails Check Paths unless it carries the `port` label. Template sync proposes the template's changes as one pull request labeled `template-sync`, and nothing lands on main until a person merges it.

**The scene:** footage-led, all from read-only `gh` against `Azure/osdu-spi-partition`. One upstream move carries claim 1: the 22 October 2026 sync (#200), its tracking issue (#201) and that issue's label history, and the cascade pull request (#202), with a station strip across the top naming 104's stations as they light. The one failure is the 15 October cascade that stopped on upstream's move to Java 25: #181's labels, the failure issue #182, the fix in the fork-owned provider pom (#183), and a person's re-dispatch. Claim 2 is the port label: a real Check Paths failure (#177, a Dependabot pull request on the root pom) and a real declared port (#164). Claim 3 and the easy mistake are template sync: #195, #174 updated in place, and the myth's check. Everything stays at level 200: what the labels and checks said, and what a person did. How `fork_upstream` is generated, the filter and Check Paths' file list are P304's; reading a red lane run and `human-required-is-a-note` are S305's.

**Made from:** new. A read-only `gh` take on 24 October 2026 (the piece's `source/take/footage/take.sh`); no lesson cut is reused. Boards draw only what a terminal does not: the station strip, the gap in the label history, two file cards for who owns a path, and one drawn diff marked as drawn.
