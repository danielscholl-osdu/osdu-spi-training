# Fieldnote 07 · Things that are not true

**Status: in production.** Cut from lesson 07 (`chapters['not-true']`) and `src/content/myths.js`. Aim for about 2 minutes 50 seconds.

**Who is watching:** an engineer who has been through the path, or one who is stuck right now. **What they should believe after it:** each of these assumptions is reasonable and wrong; every one has an owner to ask and a command that shows that owner's view; and provisioning, convergence, readiness, and proof are different signals.

**The shape is different from the other lessons.** Lesson 07 has no map, claims, or example. The episode is seven quick beats, one per theme in the order the page lists them, each with one assumption. Each beat sets the same four things in the same places, so the viewer learns the layout once: the assumption in quotes, the owner chip in its owner color, what is true, and the command with its tool chip. The seven are the ones the earlier Fieldnotes do not already show; each episode's own easy mistake is left to that episode.

**The scene:** a field-check card on the sheet, the same layout for every beat, with a small concept drawing beside it that changes per beat. The theme title sits above the card as a kicker. Owner colors follow the lesson's legend. One generated illustration carries the recall.

## Chapters

The chapter file starts a chapter at n3 to n9, one per theme, titled with the theme's title from `mythThemes` in `src/content/myths.js` (the bold text above). The cut-from record stores, as they stand at the cut: the two outcomes, and for each theme the myth id and its claim. The seven myths are `smoke-proves-api`, `reapply-retries`, `role-assignment-missing`, `certificate-means-encrypted`, `teardown-green-means-deleted`, `template-sync-overwrites`, and `restore-always-restores`.

Each theme chapter is `{ time, theme }` in `src/content/videos.js`, and the cut-from record keeps `themes: [{ theme, mistake: { id, claim } }]` beside the two outcomes, so a change to any of the seven claims fails `npm test`.

## Word list the narration must keep

- Each beat says the assumption as written, then what is true in the myth's own terms. No beat adds a cause the myth does not state.
- The smoke test proves infrastructure and GitOps readiness on the bare profile; a non-bare run still proves only the network and TLS path.
- `spi reconcile` forces one attempt; it does not fix a terminal stall.
- Port 80 serves API routes in every ingress mode; the narration never says the certificate is wrong.
- The orphan sweeper exists; the stale-pin sweep is designed, not wired, and stays out of the narration.
- Owner names are the lesson's: CLI + Bicep, Flux, You, the operator, the service fork.
