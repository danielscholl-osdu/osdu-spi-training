# Fieldnote S206 · Ship it through the line

**Status: published.** Level 200, the sixth episode of the service path. Its companion page is `chapters['ship-it']`, and its cut-from record is in `src/content/videos.js`; the curriculum entry is `S206` in `src/content/curriculum.js` (teaches `pull-request-checks`, uses `six-stations`, `proved-before-release`, `release-tags-existing-image`, `line-and-product` and `suite-from-deployed-commit`, home of the myth `acceptance-needs-a-release`).

**Who is watching:** an engineer on the service path who has proved a change from their desk (S205) and is about to open a pull request against their service's fork. **What they should believe after it:** two required checks, CodeQL and Validation Summary, gate a merge into `main`, and Validation Summary speaks for the build, the image and the lane; a code owner approves after the last push, and every review thread is resolved; a pull request from a branch in the fork gets an image named by its digest and a turn in the shared stack before it merges, and the push to `main` builds and proves the merge commit's own digest; a lane that fails because the shared environment wasn't ready passes on a re-run with the same image; and no release is needed for any of it.

**The scene:** footage-led, from read-only `gh` commands against `Azure/osdu-spi-partition`. The claim is taught from the live ruleset on `main` and the pull request's required checks. The traced example is one pull request, #197, from open to merge: its run's first try of the lane, which failed because the shared environment wasn't ready, the re-run that passed on the same digest, the summary comment drawn red then green from the API, and the push run on `main` for the merge commit. The easy mistake's check is the latest release beside the lane's run on `main` and the release pull request, still open. Everything stays at level 200: real commands and their output, the usual path, and one failure. No maintenance, borrowing mechanism, run-owned pins, or reading a red lane in depth; those are P205's and S305's.

**Made from:** new. A take of thirteen read-only `gh` commands recorded on 24 October 2026 (`source/take/footage/` in the piece), and two API reads drawn as boards: the summary comment's body and its edit history. No earlier Fieldnote is reused.
