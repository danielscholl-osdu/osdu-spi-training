# The process record

The site went through eight iterations between the evening of Friday 11 September and the morning of Monday 14 September 2026. Each iteration answered one or more reviews. The reviews are kept exactly as they were delivered; the iteration records say what was done about them.

Eleven reviews came from outside the build session: nine of the site, and two of the case study itself, one by Codex and one by an adversarial Claude subagent briefed as three sceptical readers. The first was a multi-agent concept review run as a Claude Code workflow. The rest were produced by OpenAI Codex working against the published site or a local checkout, each on its own `codex/review-*` branch, and pasted into the orchestrator session by the owner. The reviews are unchanged except that absolute local paths in their evidence links were made repository-relative, and the supplied PDF guides some of them cite are no longer kept in the repository. None of the review files names its author; the attribution here comes from the session records described in the [case study](../case-study/README.md).
