Three checks · what each one proves, and what it does not
Check 1 · hop 3
Sidecar
Caller authentication
Proves
the token came from an accepted Entra issuer, names a listed audience, and is signed
Not
that OSDU accepts the request · RequestAuthentication alone does not require a token
Check 2 · hop 4
Entitlements
OSDU authorization
Proves
this app id and user may do this · a caller is projected as itself, never a fixed principal
Not
anything about Azure · a human token arrives as that human, so hand tests need an app-only token
Check 3 · hop 6
Workload Identity
Azure access
Proves
the pod's token federates to the shared UAMI and Entra issued a resource token
Not
that a Cosmos-native data-plane grant exists or has propagated · an ARM role grant is not evidence
Where it fails · five boundaries · 401 or 403 alone names none of them
Before hop 2
Bearer in the clear
Port 80 serves the API routes in every ingress mode, nothing redirects. An http:// URL sends the token in the clear.
Hop 3 · sidecar
401 or 403, empty app id
Issuer, audience, or signature fails. An unlisted audience skips validation and the Lua exits early.
Hop 4 · service
403, identity present
Entitlements denies this app id or user. Inspect service authorization, partition config, groups.
Hop 6 · exchange
No Azure token
Check the ServiceAccount, the opt-in label, injected token-file settings, and the UAMI federation subject.
Hop 7 · Azure
Azure refuses the token
Cosmos roles are Cosmos-native, invisible to az role assignment. Propagation 5 to 15 min. Clients cache at startup, so a fresh grant may need a pod restart.
No keys · Azure data services use Entra authentication
Local auth off
Cosmos, Service Bus, Storage
disableLocalAuth hardcoded on Gremlin, every partition SQL account and Service Bus namespace. Storage shared-key off.
Placeholders
The literal DISABLED
Per-partition key and connection secrets hold it because the partition record names them. Not a credential.
The documented gap
Community indexer-queue
Its subscription client builds a Service Bus connection string regardless of the flag and reads DISABLED. Records-changed indexing needs a Workload-Identity-capable image.
The verdict
Three questions, three answers
A valid Entra token is not an entitlement, and a federated exchange is not a Cosmos grant. The record is read only when all three checks pass.
