# Documentation

Two kinds of material live here. The first supports the training site itself: scripts, narration, generation briefs, and reference assets that the site, its tests, or its posters depend on. The second is the record of how the site was built over four days in September 2026, kept for the hackathon case study.

## Site material (do not move)

| Path                                                                             | What it is                                                                                                                                                        |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `audio-source-notes.md`                                                          | Marker map for every recording and the wording the narration should correct. Read it before producing narration.                                                  |
| `azure-spi-brief-script.md`                                                      | The approved script for the two-minute brief. A recording is replaced from a script like this, never by editing its transcript.                                   |
| `azure-spi-introduction-source.md`, `azure-spi-introduction-generation-brief.md` | The written source and the NotebookLM prompt behind the current introduction episode and brief, and the retired Start video.                                      |
| `azure-spi-orientation-source.md`, `azure-spi-orientation-generation-brief.md`   | The earlier orientation source and prompt, superseded the same day but kept because the recordings they produced are still in the repository.                     |
| `deep-dive-stack-script.md`, `deep-dive-fork-script.md`, `start-video-script.md` | Replacement scripts drafted for approval, with the editorial notes around each.                                                                                   |
| `narration/`                                                                     | The spoken text alone for each replacement script. This is what a narrator or generator receives.                                                                 |
| `reference/`                                                                     | Supplied posters and their site-built HTML sources, generated artwork with its prompts, transcript VTT files, and the lesson 01 prototype. Preserved as supplied. |

What changed on the site and why:

- The Gateway is `platform/spi-gateway`, and managed Istio deploys `spi-gateway-istio` from it (stack #318, ADR-026, `docs/design/gateway-ingress.md`).
- Every service follows the `main` image its `Azure/osdu-spi-<service>` fork publishes to GHCR, and an environment can record a trusted mirror per service (stack #371 in 0.30.0, ADR-033, ADR-017). Community images are no longer a source. The provisioned ACR now receives local builds from `spi service pin --source` and `spi build` (ADR-038).
- `spi check` reads the signed-in identity's subscription permissions and shows the Azure row as SKIPPED without a sign-in; `spi up` repeats the check before changing Azure (stack #244, `src/spi/permissions.py`, `docs/install.md#permissions`). The deployer needs Contributor plus a conditioned Role Based Access Control Administrator, not User Access Administrator.
- `spi down` asks the person to type `y` unless `--force` is passed (stack #264, `src/spi/cli.py`).
- `env-refresh` runs on weekdays at 04:00 UTC and advances every canonical image with `spi service refresh --forks`; `env-upgrade` has a 6.5-hour budget (`docs/design/environment-lifecycle.md`). The backing-environment, one-request, and inside-the-cluster posters were edited and re-rendered for these and the Gateway move.
- The community partition repository removed its Azure provider and Azure CI in `a2c4f7b7` on 20 October 2026, and the fork generated `fork_upstream` from it that day (`ec389615`); `main` still holds `provider/partition-azure`. Thirteen forks under `Azure/` (partition, entitlements, legal, schema, storage, search, indexer, indexer-queue, file, workflow, crs-conversion, crs-catalog, unit) carry `.spi/service.yaml`, checked through the GitHub API on 22 October 2026.
